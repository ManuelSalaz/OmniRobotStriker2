Detailed Description

Control omnidireccional de 3 ruedas con ESP-IDF.

Inicializa sensores (AS5600 I2C/analógicos, BNO055), motor PWM, servidores HTTP/TCP para comandos y tareas FreeRTOS de fusión de sensores y control PI por rueda con sujeción de rumbo.
